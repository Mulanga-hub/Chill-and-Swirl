# Chill & Swirl Ice Cream – Changelog

This document records the development, improvements and updates made to the Chill & Swirl Ice Cream website across Parts 1, 2 and 3.

## Part 1 – Planning and Design

- Established the Chill & Swirl Ice Cream business concept.
- Identified the target audience and planned the website's purpose.
- Planned the website structure and main pages.
- Selected the website's visual style, colours and layout.
- Planned the products and services to be presented on the website.

## Part 2 – Website Development

- Created the main website pages: Home, About, Menu, Inquiry and Contact.
- Added navigation to allow visitors to move between pages.
- Added website content, images and product information.
- Created the main stylesheet to control the website's appearance.
- Added responsive styling for different screen sizes.
- Organised website files into separate folders for CSS, JavaScript and images.

## Part 3 – Functionality, Forms and SEO Improvements

### JavaScript Functionality

- Added an interactive FAQ accordion.
- Added an image gallery lightbox.
- Added menu product search functionality.
- Added JavaScript validation to the Inquiry form.
- Added dynamic inquiry responses based on visitor selections.
- Added JavaScript validation to the Contact form.
- Added contact form processing that prepares an email using the visitor's details and message.

### Forms

- Improved the Inquiry form with customer details, inquiry categories, product selection, quantity and message fields.
- Added validation to check required fields and input formats.

- Added an interactive Google Maps embed to the Contact page.
