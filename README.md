# CHILL & SWIRL ICE CREAM WEBSITE

## 1. Project Introduction

Chill & Swirl Ice Cream is a fictional ice cream business website developed as part of a Web Development project. The business operates in Pretoria Central and Sunnyside, Pretoria, South Africa.

The website provides customers with information about the business, its products, available services and contact details. It also allows visitors to explore the menu, submit product enquiries and communicate with the business.

The main purpose of the project is to create an attractive, user-friendly and responsive website that represents the Chill & Swirl brand while demonstrating the practical application of HTML, CSS and JavaScript.

---

## 2. Project Overview

Chill & Swirl Ice Cream focuses on providing customers with a variety of affordable ice cream products and desserts.

The website was developed through three project stages:

- **Part 1 – Planning and Design:** Establishing the business concept, identifying the target audience and planning the website.
- **Part 2 – Website Development:** Creating the website pages, navigation structure and visual layout using HTML and CSS.
- **Part 3 – Functionality and SEO:** Introducing JavaScript functionality, interactive features, form validation and search engine optimisation.

Each stage contributed to the development and improvement of the final website.

# 7. PART 2 – WEBSITE DEVELOPMENT

Part 2 focused on translating the original website concept into a functional website using HTML5 and CSS3.

The website was organised into five main pages.

### Website Pages

**1. Home Page – index.html**

The home page introduces Chill & Swirl Ice Cream and provides visitors with an overview of the business.

**2. About Us – about.html**

The About Us page provides information about the business, its background and its purpose.

**3. Menu – menu.html**

The Menu page displays the different ice cream products and desserts offered by the business.

**4. Inquiry – inquiry.html**

The Inquiry page allows customers to ask questions about products, availability, orders, events and special requests.

**5. Contact – contact.html**

The Contact page provides business contact information, operating hours, location information, a Google Maps embed and a contact form.

### HTML Development

HTML5 was used to:

- Structure the website pages.
- Create headings and paragraphs.
- Add images and navigation links.
- Organise content into sections.
- Create forms and input fields.
- Add semantic website elements.

### CSS Development

CSS3 was used to:

- Style the website.
- Establish consistent colours and typography.
- Format navigation menus.
- Style images and content sections.
- Improve the appearance of forms and buttons.
- Create responsive layouts for different screen sizes.

### Website Structure

The website uses a shared navigation system to allow visitors to move between the five pages.

Consistent styling was applied throughout the website to maintain a recognisable visual identity.

# 8. PART 3 – FUNCTIONALITY AND SEARCH ENGINE OPTIMISATION

Part 3 focused on improving the website through JavaScript functionality, interactive features, form validation and SEO techniques.

### 8.1 JavaScript Functionality

JavaScript was implemented to improve the website's interactivity and user experience.

The following features were developed:

**FAQ Accordion**

Allows visitors to expand and collapse frequently asked questions.

**Image Gallery Lightbox**

Allows visitors to open an image in a larger lightbox view and close it using the close button, clicking outside the image or pressing Escape.

**Menu Product Search**

Allows customers to search for products displayed on the menu page. Products that do not match the search are hidden, and a message is displayed when no matching products are found.

**Interactive Google Maps**

A Google Maps embed was added to the Contact page to allow visitors to explore the Pretoria area and navigate the map using its controls.

### 8.2 Inquiry Form

The Inquiry page includes a form that allows customers to submit product and service enquiries.

The form collects:

- Full name.
- Email address.
- Telephone number.
- Inquiry type.
- Product selection.
- Quantity.
- Message or special request.

JavaScript was implemented to validate the form and display a response based on the selected inquiry type.

Different responses are displayed for general questions, product orders, product availability, events and special requests.

### 8.3 Contact Form

The Contact page includes a separate form for general customer communication.

The form collects:

- Full name.
- Email address.
- Telephone number.
- Message type.
- Full message.

The contact form uses HTML validation and JavaScript to collect and process the customer's information.

When submitted, the website prepares an email addressed to the business using the customer's default email application. The customer can review the prepared message and send it.

### 8.4 Search Engine Optimisation (SEO)

SEO techniques were introduced to improve the website's organisation and search engine visibility.

The following techniques were applied:

- Descriptive page titles.
- Meta descriptions.
- Meta keywords.
- Structured HTML headings.
- Descriptive image alternative text.
- Internal navigation links.
- Responsive website styling.
- Clear page content and organisation.

### 8.5 Form Validation

Form validation was implemented to improve the accuracy of customer submissions.

Validation includes:

- Required fields.
- Email format checks.
- Telephone number format checks.
- Minimum text lengths.
- Quantity restrictions.
- Appropriate validation messages.

These features help prevent incomplete or incorrectly formatted submissions.
